# Subnet-Calculator
1 - Parse IP address with prefix or subnetmask. Example: 192.168.10.1/24 or 192.168.10.1 255.255.255.0
2 - Calculate the Netwrok ID and Broadcast IP address
3 - Calculate all Host ranges with Network ID, Broadcast IP address and the usable IP addresses (CIDR)
4 - After finishing the above work on taking topologies and generate a full VLSM allocation table
